# Dormant No Man's Land native boundary

Run `python3 porting/tests/no-mans-land-native/run.py --java-home JAVA8 --classpath NATIVE_CLASSPATH`. No downloads. Windows execution is untested.

All three production classes compile whole against actual Forge 1.12.2/MCP stable39: BiomeGenNoMansLand, BiomeDecoratorNoMansLand, WorldGenSurfaceSpot. The terminal proof has 18,199 assertions. The existing ForgeEventNativeLauncher applies the genuine Forge event transformer; events and TerrainGen use actual native classes, not platform stubs.

The original MainRegistry activation remains commented out. Loading the biome does not register it or add it to generation. Explicit initDictionary is a native biome-registration-phase hook only; tests invoke it in a disposable JVM. It must not simply be uncommented in old preInit timing. Native registry key hbm:no_mans_land replaces the old hardcoded numeric ID99; migration of old saves using that numeric ID is not certified. Existing foreign registry ownership is rejected rather than overwritten.

Tests cover native low-plains height .125/.05, fixed sky/grass/foliage/water colors, exact hostile weight/group, original shared mutable spawn-list behavior, native dictionary tags and warm weight5. Surface spots compare an independent transcription of the original algorithm across20 seeds, three radii, three probabilities and three heights: exact block writes and next RNG state, dirt/grass identity, depth2, metadata0 and flag2. Decorator tests compare callback order, RNG and event cancellation across64 seed/mask combinations, including original fifty water attempts. The original subclass gravelGen is intentionally another sellafield_slaked surface generator; parent gravelAsSandGen maps to super.gravelGen, not this shadowing field. This original quirk is preserved.

Boundaries: ModBlocks.sellafield_slaked and EntityUndeadSoldier are explicit NTM collaborators. A real World subclass records terrain reads/writes; vanilla ore generation is intercepted at the native inherited delegation boundary. Generic native vanilla ore/tree/grass/dead-bush feature internals are not certified as identical to1.7.10. Water tests exercise the real native generator's early rejection on the recording terrain, not a live generated landscape. There is no complete world-generation, registration-event bootstrap, save-migration or in-game biome proof. No feature is newly activated by this migration.
