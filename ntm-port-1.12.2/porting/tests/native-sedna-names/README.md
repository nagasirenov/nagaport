## Reproduction

Use Java 8 and the existing native Forge+AE2 classpath, no downloads. Compile ChainScanner.java, DestinationScanner.java and ReturnProof.java with javac -cp JAVA8/lib/tools.jar -d OUT. Generate a sorted file list of all module src/main/java/**/*.java; execute each scanner with java -Xmx3G -cp OUT:JAVA8/lib/tools.jar CLASS FILE_LIST CLASSPATH_FILE. Before attribution uses this exact Git baseline for the 17 manifest paths; after uses the transformed files. For controls append a temporary .java copy of Controls.java.in to the list. A separate control-only wrong argument intentionally contributes one diagnostic; production-independent-after.log excludes controls.

Run ReturnProof on the exact production ItemGunBaseNT.java, then python3 verify.py for unchanged-owner pins, reversible edits and scanner equality. verify.py --apply only accepts exact original or target file bytes. check-controls.py uses the task's cached Java8 scanner output path; adjust it if reproducing elsewhere. It rejects three deliberately changed temporary owner copies. Historical pinned runtime evidence remains available in Git and the native-translation-names directory. No synthetic game/platform API implementation is used.
