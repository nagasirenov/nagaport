Base CP52 e0d436953a26ba3e7cb58effa31adc48282eb501. Exactly 584 call names in 262 production files, with 148 argument casts where the attributed primitive differs from the original descriptor. No RNG calls, formulas, evaluation order, helper emulators, imports or unrelated bytes change. Existing production safeClamp NaN comparison is deliberately preserved, not repaired.

Selected calls: floor_double227, floor_float10, sqrt_double77, sqrt_float2, clamp_double78, clamp_float64, clamp_int77, wrapAngleTo180_double16, wrapAngleTo180_float18, ceiling_double_int10, ceiling_float_int5. Unresolved/error/reference-typed arguments remain untouched. The scanner resolves the receiver to the actual net.minecraft.util.math.MathHelper TypeElement and requires valid primitive widening into the old signature. Whole-unit class/variable/type-parameter shadow rejection is conservative. Static imports and nonliteral Unicode method identifiers are excluded. Native overload merging makes a name-only rewrite unsafe: floor_double(16777217) formerly converted int to double, but floor(16777217) chooses float and loses one. Explicit casts preserve the old JVM descriptor and conversion point, including float rounding and long conversions; every original argument is still evaluated once in original order.

The native names are joined by SRG IDs, not guessed. mapping-provenance.json pins the original joined.srg, MCP39 CSV and original client. No old-math substitute is used. The explicit overload mutation control demonstrates an actual mismatch. RNG and stateful methods are outside this batch.
