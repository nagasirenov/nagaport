# Native resource path case, checkpoint 8

The pinned 1.12.2 `ResourceLocation` lowercases both namespace and path using `Locale.ROOT`. Actual native model-loading tests therefore request `models/armor/ajr.obj`, even when source code supplies `models/armor/AJR.obj`. A case-insensitive test filesystem lookup would hide a production failure on case-sensitive resource packs/filesystems.

This batch renames exactly the ten referenced mixed-case OBJ resources and the EMP texture listed in `resource-case-migration.json`. Bytes, model geometry, materials, UVs, and texture pixels are unchanged. Source resource literals are retained; native normalization performs the lookup. `check-resource-case.py` checks every old path is absent, the canonical path is present, and bytes match the recorded original SHA-256. Native CPU/VBO fixtures use the actual target ResourceLocation, not a permissive path search. The EMP native fixture additionally checks its model and texture resource paths and hashes.

Before this bounded fix, an inventory found 812 mixed-case paths among 8645 asset files, with no case-fold collisions. Ten were referenced models (including Ring); the eleventh model, `missileDoomsday.obj`, had no literal loader reference in the audited factories and is not changed. Textures, sounds, structures, languages, shader and disk resources need separate reference/owner audits; not every file under assets is a Minecraft ResourceLocation asset. Do not blindly rename all of them or declare the broader inventory accepted. After these eleven renames, 801 mixed-case paths remain.

`BombGenericLarge.obj` is absent in the supplied baseline and remains absent. The factory inventory includes its unregistered RenderBombMultiLarge loader; the native test explicitly expects that IO failure rather than inventing replacement geometry or counting it as a loaded model. Bundled asset checks are headless resource/parser/buffer checks, not a resource-pack reload or live rendered-game acceptance.
