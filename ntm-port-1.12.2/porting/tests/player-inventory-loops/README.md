# Player inventory foreach vacancy boundary (CP86 candidate)

Base CP85 abe006a0845275e8be52417967ac8ebf6f283a52. Ten already-compiling legacy loops across eight files still treated null as an absent slot. Native InventoryPlayer fills absent main/armor slots with canonical ItemStack.EMPTY. In particular HazardSystem's armor loop otherwise sends that absent sentinel to applyHazards. This batch converts only the loop-local canonical sentinel to null before the exact original body. It does not modify any slot, stack, count, NBT, callback, branch, iterator or recipe. No `isEmpty()` normalization: every noncanonical zero/negative/AIR/null-item stack remains the same object. NativeHeldItem already uses this exact identity boundary.

LoopScanner attributes genuine InventoryPlayer mainInventory/armorInventory fields and ItemStack loop variables. All 11 such loops were inspected; HEVBattery already has native empty handling and is excluded. Ten insertions, eight exact CP85 whole-file inverses, line endings and all original body bytes retained. Native iteration was already present before this change; this is not an adapter for old array iterator behavior or arbitrary concurrent mutation. Null iterable still throws. The local variable is not final and no modified loop captures it in a lambda/anonymous class.

`python3 porting/tests/player-inventory-loops/run.py` uses cached genuine Java8/Forge dependencies only. It compiles all ten actual inserted normalizers into small loop-boundary projections against real InventoryPlayer main/armor lists. 4,534 assertions cover original null-array vacancy interpretation, exact visit order/identity, noncanonical empty stacks, unchanged inventory slots/count/NBT and null iterable. A compiled missing-normalizer mutant fails. These are boundary projections, NOT complete handler, charge transfer, ammunition, key, conveyor, or radiation execution. Whole original loop bodies are protected by byte inversion, not falsely claimed as runtime-tested.

The native read/write family is integrated separately. Remaining old item semantics, malformed stack identity exposure, quantity operations, inventory array aliases and full mod compilation still need migration. This does not establish player inventory or dropped-item irradiation correctness in game. No radiation formula, shielding, decay, callback or emission mechanic changed.
