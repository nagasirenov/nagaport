WORLD AND SUPER-CHAIN DETAILS
ItemCustomLore uses only player.worldObj.rand in undefined-item tooltip. Native World may be null; retain the existing UNDEFINED fallback without needing Minecraft.getMinecraft().player.
ItemVOTVdrive uses only player.worldObj: provider.dimensionId twice and CelestialBody.getBody(world) once. Use world.provider.getDimension() and guard nullable world; skip world-relative guidance or give an unknown requirement rather than inventing a current body.
No tooltip in either closure needs actual player state or Minecraft player access.
Only ItemMissile, ItemAmmo and ItemVOTVdrive forward super.addInformation; convert forwarded World and ITooltipFlag arguments too.
ItemMissile intentionally calls lore superclass only in its launchable branch. ItemSchraranium intentionally does not call lore superclass.
ItemCircuit tooltip body is entirely commented out; preserve as no-op or remove override without changing behavior.

ENUM ICON/LAYER CONTRACTS TO PRESERVE
ItemEnumMulti default: multiTexture uses <iconString>.<lowercase enum>; single texture uses iconString. Invalid metadata is normalized by EnumUtil.grabEnumSafely.
ItemAmmo.registerIcons: custom hbm:<IAmmoItemEnum.getInternalName()>, not enum/base naming.
ItemConserve, ItemDrillbit, ItemFlask, ItemPistons, ItemZirnoxRod.registerIcons: <iconString>_<lowercase enum>, not dot naming. ItemFlask texture separator differs from inherited localization separator.
ItemGenericPart.registerIcons: custom hbm:<EnumPartType.texName>, not enum/base naming.
ItemWatzPellet.registerIcons: generated TextureAtlasSpriteMutatable via LegacyIconRegister.registerGeneratedSprite; retain live/depleted palette and desaturation, unique placeholder hbm:watz_pellet-<enum name><registry path>, and hbm:watz_pellet fallback. getIconFromDamage returns fallback when generated icon is null.
ItemBedrockOre: two layers. Layer 0 default base, white; layer 1 hbm:ore_overlay (hbm:ore_overlay_b for BISMUTH), tinted enum color. Preserve bismuth overlay branch.
ItemChemicalDye: two layers. Layer 0 default base, white; layer 1 hbm:chemical_dye_overlay, tinted enum color.
ItemVOTVdrive: exactly two layers. Layer 0 hbm:votv_f; layer 1 hbm:votv.<body name>, with ORBIT using lowercase orbit. Its legacy overlay callback directly indexes metadata, unlike base safe enum lookup.
ItemByproduct and ItemProduct: shared base texture tinted with enum color on any pass.
Lore-side ItemSchraranium: base icon switches to hbm:ingot_nikonium only when both enableLBSM and enableLBSMFullSchrab are true.
